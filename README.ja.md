# kids


日本の省庁による公開イベントである2017年「こども霞が関見学デー」のイベントを検索・絞り込みするためのシンプルなWebアプリケーションです。

**ライブデモ:** [fukuno.jig.jp/1816](http://fukuno.jig.jp/1816)

![アプリケーションのスクリーンショット](https://fukuno.jig.jp/img/kids2017.png)

## 機能

- **キーワード検索:** すべてのイベント詳細から即座に検索します。
- **カテゴリー別絞り込み:** 種類によってイベントを絞り込みます:
  - 学ぶ、ふれる・感じる、体を動かす、奏でる、乗る、見る、作る・描く、収穫・採集する、その他
- **対象者別絞り込み:** 適切な年齢層を選択します:
  - 就学前、小学生低学年、小学生中学年、小学校高学年、中学生、高校生以上

## 仕組み

これは、素のHTML、CSS、JavaScriptで構築されたクライアントサイドアプリケーションです。Google Sheets APIへのJSONPリクエストを使用して、公開されているGoogleスプレッドシートからプログラムデータを動的に取得します。その後、データは解析され、検索および絞り込み可能なリストとしてレンダリングされます。

## データソース

このアプリケーションは、2017年のイベント用に公開されたオープンデータを使用しています。

- **ソース:** [平成29年度こども霞が関見学デー プログラムオープンデータ](https://docs.google.com/spreadsheets/d/1FEhoCeSrnW-D8YLSfy3wMD
